🎨 Car Sketch Project

Convert car photographs into beautiful pencil sketch artwork using computer vision. This project applies image processing techniques to create artistic sketches from original photos with multiple style options.

Features

  • Pencil sketch effect using blend mode algorithms
  • Edge detection for line-art style conversion
  • Cartoon posterization with edge overlay
  • Batch processing support with custom output names
  • Automatic image enhancement and sharpening

Technology Stack

  • Python 3 with OpenCV (cv2) for image processing
  • NumPy for numerical operations
  • Gaussian blur and Canny edge detection algorithms
  • Kernel-based image filtering for enhancement

Usage

  • Basic: python3 generate_sketch.py porsche_911.jpg
  • Advanced: python3 generate_sketch.py input.jpg output.png edge
  • Supports pencil, edge, and cartoon styles
