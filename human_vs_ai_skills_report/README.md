# Human Technical Skills vs Artificial Intelligence

This folder contains a simple report comparing human technical capabilities with artificial intelligence.

## Contents
- index.html — the report page

## Summary
Humans are strongest in judgment, ethics, empathy, and contextual understanding, while AI is strongest in speed, scale, pattern recognition, and automation.

## Generate the report
Run the generator script to create a simple HTML artifact for this report:

```bash
python3 generate_report.py
```

This writes [generated_report.html](generated_report.html) in the same folder.
