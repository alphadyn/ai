# Prime Numbers

This folder contains a simple Python utility for identifying prime numbers.

## What it does
- Checks whether a number is prime
- Finds all prime numbers up to a specified limit

## Usage
Run the script with Python:

```bash
python3 prime_finder.py
```

This will print all prime numbers up to 1000 by default.

## Main file
- `prime_finder.py` - contains the prime-checking and prime-list generation logic
