# Legal Docketing App

This folder contains a complete, functional legal docketing application built as a single-page web app.

## Features
- Create and manage legal matters
- Add docket events and deadlines
- Track upcoming and overdue events
- Persist data locally in the browser
- Delete matters and associated events

## Run it
Open the file in a browser, or serve the folder locally with a simple web server.

Example:

```bash
cd /Users/kanayo/Documents/GitHub/ai/legal_docketing_app
python3 -m http.server 8000
```

Then open http://localhost:8000/
