Market Curve Lab

Rank and search all 500 S&P 500 companies, then explore adjusted historical performance, least-squares trendlines, and recent concavity for a selected ticker. Other listed stocks are searchable too.

Start the local data service
  1. Open a terminal in the market_curve_lab folder.
  2. Install dependencies: python3 -m pip install -r requirements.txt
  3. Run: python3 app.py
Open Market Curve Lab ↗

The app needs a running local Python service and an internet connection for market data.
