# Business Site

This folder contains a polished single-page marketing website for a fictional AI company.

## What is included
- A responsive landing page in `index.html`
- Styling in `styles.css`
- Visual assets in the `assets/` directory

## How to view it
Open `index.html` in a browser to see the page.

## Notes
- The site is designed for offline viewing.
- It includes sections for the platform, solutions, about, and contact information.

## Generate the report
Run the generator script to create a simple HTML output:

```bash
python3 generate_report.py
```

This writes [generated_report.html](generated_report.html) in the same folder.
