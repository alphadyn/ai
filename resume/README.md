# Resume

This folder contains a polished HTML resume for an AI software engineer.

## What is included
- A single-page resume in `index.html`
- Sections for experience, selected projects, skills, education, and certifications

## How to view it
Open `index.html` in a browser to display the resume.

## Notes
- The resume is a static portfolio-style document.
- It is suitable for showcasing front-end presentation skills as well as career experience.
