# AI Projects Repository

This repository contains a small collection of standalone projects and demo pages focused on AI, web development, finance, healthcare, and gaming content.

## Projects

- [business_site](business_site/) - A polished single-page marketing website for an AI company.
- [crawler_indexer](crawler_indexer/) - A Python script that indexes content from a URL, file, or directory.
- [prime_numbers](prime_numbers/) - A simple Python utility for checking and listing prime numbers.
- [resume](resume/) - A polished HTML resume for an AI software engineer.
- [business_plan](business_plan/) - A business plan presentation for an AI tech startup.
- [medical_center_plan](medical_center_plan/) - A business plan presentation for a medical center.
- [index_fund_report](index_fund_report/) - A report on index funds grouped by risk level.
- [sp500_quarterly_returns](sp500_quarterly_returns/) - A report highlighting strong quarterly performers in the S&P 500.
- [game_videos_site](game_videos_site/) - A simple website with links to gaming videos.

## How to use

Most of the web-based projects are simple HTML files that can be opened directly in a browser.

For the Python projects, run them from their respective folders with Python 3.

Example:

```bash
python3 crawler_indexer/indexer.py https://example.com --max-pages 5 --output index.json
python3 prime_numbers/prime_finder.py
```

## Notes

This repository is intended as a collection of sample projects and demos rather than a single production application.
