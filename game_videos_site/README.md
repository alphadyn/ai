# Game Videos Site

This folder contains a simple static website that showcases a collection of gaming video links.

## What is included
- A single-page HTML layout in `index.html`
- A curated list of game categories with links to video content

## How to view it
Open `index.html` in a browser to explore the page.

## Notes
- This is a lightweight demo site with no backend or dependencies.
- It is useful as a simple example of a content-focused landing page.
